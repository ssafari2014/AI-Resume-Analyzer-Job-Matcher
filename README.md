# 🔍 AI Resume Analyzer + Job Matcher

🎯 یک ابزار NLP هوشمند برای تحلیل رزومه PDF و مقایسه آن با آگهی‌های شغلی.  
شامل:
- استخراج مهارت‌ها با spaCy
- تطبیق مهارت‌ها با متن آگهی (fuzzy matching)
- محاسبه درصد تطابق برای تصمیم‌گیری سریع

## 🛠 تکنولوژی‌ها:
- Python
- spaCy
- fuzzywuzzy
- PDFMiner (برای استخراج متن از PDF)

## 🚀 طریقه اجرا:
```bash
pip install -r requirements.txt
python main.py
